링크 추가 기능을 구현해

- 사용자가 새 링크를 추가하면, links 테이블에 보관해
- 새 링크 페이지의 추가(저장)버튼의 중복 클릭을 막아서, 여거래의 링크가 동시에 추가되지 않도록 해줘
- 새 링크 페이지의 폴더를 선택하는 셀렉트 박스에 현재 folders 테이블에 보관된 모든 폴더의 목록을 나열해
- 추가된 링크들을 인덱스 페이지나 폴더별 페이지에 불러와서 보여주는 기능도 추가해.

# 기타 행동사항

기능을 구현하면 설치된 모든 브라우저에서 정상 작동하는지 테스트 해보고,
테스트가 성공하면 알려주고, 테스트가 실패하면 어떤게 잘못되었는지 다시 분석해서 수정해.

크리티컬한 BASH 커맨드가 아니면 묻지말고 그냥 실행해줘.

- 이외의 시키지 않은 기능까지는 굳이 구현하지마
- MCP를 활용ㅇ해서 테이블 구조를 먼저 확인하고 작업을 진행해.
