폴더 추가 기능을 구현해

- 사용자가 추가한 폴더를 folders 테이블에 추가해
- 폴더 추가 버튼의 중복 클릭을 막아서, 여러개의 폴더가 동시에 추가되지 않도록 해줘
- 좌측 사이드바에 folders 테이블에 보관된 폴더들을 불러와서 순서대로 나열해줘
- 이외의 시키지 않은 기능까지는 굳이 구현하지마
- mcp를 활용해서 테이블 구조를 먼저 확인하고 작업을 진행해

# 기타 행동사항

기능을 구현하면 설치된 모든 브라우저에서 정상 작동하는지 테스트 해보고,
테스트가 성공하면 알려주고, 테스트가 실패하면 어떤게 잘못되었는지 다시 분석해서 수정해.

크리티컬한 BASH 커맨드가 아니면 묻지말고 그냥 실행해줘.
